_**Название проекта**_: Платформа для турниров по бадминтону (Volanchiki.com)

**Описание проекта**:
Веб-приложение для проведения турниров по бадминтону.
Система позволяет регистрироваться в систему, просматривать расписание, турнирные таблицы и результаты игр в реальном времени, а также принимает заявки на турниры и составляет рейтинг участников по результатам соревнований.
 
**Функциональные возможности**

- Регистрация и авторизация участников и организаторов (по номеру телефона/ почте).
- Подача заявок на турнир (данные из личного кабинета и аккаунта напарника)
- Просмотр сеток/таблиц турнира по категориям (MD, WD, XD, MS, WS).
- Отображение групп (A, B, C, D, F, E, G) и итоговых таблиц.
- Просмотр личного кабинета с историей участия в турнирах.
- Просмотр рейтинга в парном и одиночном разрядах.
 
**Технологический стек (предложение)**

- Бэкенд: Java
- Фронтенд: HTML, CSS, JavaScript
- База данных: MySQL / PostgreSQL.
- Инструменты: Git, Figma
